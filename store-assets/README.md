# Microsoft Edge 商店素材 / Store assets

本目录保存可直接上传到 Microsoft Edge 加载项商店的中英文素材。商店后台需要逐个上传 PNG 文件，不要上传整个素材目录或压缩包。

The folders below contain the Chinese and English assets for the Microsoft Edge Add-ons listing. Upload the PNG files individually in Partner Center.

## 目录

- `zh-CN`：简体中文商店素材。
- `en-US`：英语商店素材。

每种语言均包含：

- `logo-300x300.png`：必填扩展徽标。
- `screenshot-1-side-panel-1280x800.png`：侧边栏截图。
- `screenshot-2-manager-1280x800.png`：管理与版本历史截图。
- `small-promo-440x280.png`：可选小型宣传磁贴。
- `large-promo-1400x560.png`：可选大型宣传磁贴。

商店文案见仓库根目录的 [`STORE_LISTING.md`](../STORE_LISTING.md)。
