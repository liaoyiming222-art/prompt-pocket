# 好用的，值得留下

《提示词口袋》32 秒原创动画。保留测试初版和独立复用小样，另行导出 v2。全片围绕虚构条目「展览介绍」，让每个操作都延续上一个动作。

| 时间 | 脚本与分镜 |
| --- | --- |
| 00–06.4 | 暖紫背景中的口袋特写。相机随着卡片后撤并转正；卡片落进入袋，字卡「好用的，值得留下」先退，模型再叠化到浏览器。 |
| 06.4–13 | 浏览器、网页输入框和原生侧栏分层。指针点搜索，出现「展览」，无关条目退下，留下同一张「展览介绍」。 |
| 13–18.2 | 视线移到输入框。先点光标，再点已存条目，文字从右向左落位；停留看清原文与侧栏源条目。复用了经过审阅的小样动作。 |
| 18.2–26.7 | 点击「预览」，补写「，并列出两个看点」，点击保存新版本。右侧层展开成历史，当前 V2 与原始 V1 同时可见；点击 V1，回看原文，V2 仍为当前。 |
| 26.7–32 | 叠化回三维实体并缓慢转正，落到产品名、「随手存，随时用」和桌面 Chrome / Edge 扩展。 |

三维镜头复用测试初版的 Blender/GLB 几何，重新编排相机、灯光和材质。操作段使用原小样 HTML/SVG 与 CSS 2.5D，沿用正式品牌图标；侧栏和网页是简化后的操作图层。原文转移的纸条是视觉隐喻。这里只演示支持直接插入的桌面网页输入框；复杂编辑器的复制回退见项目使用说明。没有录屏、用户数据、AI 输出和移动安装演示。配乐及同步提示音为新编程序合成。

打开 [预览页](preview.html)。导出为 `output/prompt-pocket-1080p60.mp4`，1920×1080、60fps、H.264/AAC。保留旧版及小样，未改变业务功能。

复现：安装本目录清单中的 Node 依赖及 Python/NumPy，设置 `FFMPEG_PATH`，可用 `PYTHON_PATH`、`BROWSER_PATH` 指向本机工具。运行 `node render.cjs --stills` 抽查镜头、`node render.cjs` 输出整片、`node playback.cjs` 验证实际播放并导出成片抽帧。生成的舞台 HTML 由已审阅小样派生，Three.js 库与模型由同仓库 v1 目录提供。验证记录在 `output/verification.json` 和 `output/playback.json`。
