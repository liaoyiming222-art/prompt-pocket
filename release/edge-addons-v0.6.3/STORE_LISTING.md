# Microsoft Edge 加载项上架资料

## 基本信息

- 扩展名称：提示词口袋
- 版本：0.6.3
- 类别建议：生产力
- 定价建议：免费
- 主要语言：简体中文（zh-CN）

## 简短说明

在网页侧边栏中保存、搜索和复用提示词，本地存储并自动保留编辑历史。

## 详细说明

提示词口袋是一款本地优先的提示词管理扩展。它在普通网页显示可拖动的悬浮球，点击即可打开 Microsoft Edge 原生侧边栏，方便随时保存和复用提示词。

主要功能：

- 从普通输入框、文本区域和常见富文本编辑区读取内容。
- 搜索已保存提示词，并插入当前网页输入框。
- 保存每次正文修改的历史版本，可随时查看和恢复。
- 管理页面支持新建、编辑、删除以及 JSON 导入和导出。
- 自动避开密码、验证码、银行卡等敏感输入框。
- 所有数据仅保存在当前浏览器，不含账号、广告、分析统计或云同步。

使用说明：允许扩展在所有网站上运行后，普通 HTTP/HTTPS 网页会显示紫色 P 悬浮球。浏览器内部页面、扩展商店、部分复杂编辑器及 iframe 输入框不支持读取或插入；无法插入时会尝试复制到剪贴板。

## 权限用途说明

- 网站访问权限（HTTP/HTTPS）：在普通网页显示悬浮球，读取用户主动选择的非敏感输入框，并插入用户选择的提示词。
- storage：在浏览器本地保存提示词、历史版本和悬浮球位置。
- downloads：仅在用户主动导出时保存 JSON 备份。
- sidePanel：显示 Microsoft Edge 原生侧边栏。
- activeTab、scripting：初始化已打开页面及恢复当前页悬浮球。

## 隐私页逐项填写（对应 Partner Center 截图）

以下填写内容按 0.6.1 的实际代码整理，更新日期：2026-09-15。各理由正文均少于 1000 字，可直接复制对应段落。数据分类是基于当前功能的判断，不代表微软已认可分类或批准发布。

### 1. 单一用途描述

提示词口袋的单一用途是在浏览器中保存、管理和复用文本提示词。用户可通过普通网页上的悬浮球打开原生侧边栏，读取最近使用的输入框内容，主动保存为提示词，再搜索、复制或插入网页输入框。管理页面提供编辑、历史版本恢复以及 JSON 导入导出。这些功能均服务于提示词的本地管理与复用；扩展不提供账号、云同步、广告或远程 AI 服务。

### 2. storage 理由

用于在当前浏览器的扩展本地存储中保存用户主动保存的提示词标题、正文、历史版本、来源网页信息，以及用于排序的最近使用时间和使用次数。同时保存悬浮球位置，并在会话存储中记录各浏览器窗口的侧边栏显示状态，以协调悬浮球显示。数据不上传到开发者服务器，也不通过浏览器同步存储同步到其他设备。用户可删除提示词或主动导出 JSON 备份。

### 3. downloads 理由

用于用户在管理页点击“导出 JSON 备份”后，将本地提示词及历史版本保存为 JSON 文件，并显示保存位置选择。扩展不在后台自动下载文件，也不读取或收集用户的下载历史。

### 4. activeTab 理由

用于响应用户主动点击浏览器工具栏扩展图标的当前标签页操作，配合 scripting 检查或重新加载当前普通网页的悬浮助手，使用户能够恢复提示词入口。该权限不用于读取浏览器历史记录、切换搜索引擎或修改浏览器设置。

注意（不要复制进理由框）：当前版本还声明了所有 HTTP/HTTPS 网站的持续权限，在这些网站上 activeTab 的授权范围存在重叠。上述文字说明现有工具栏用途，不代表该权限不可替代；若审核要求解释最小权限或删除冗余权限，应检查并精简清单后重新打包，不能靠文案声称它是必需的。本次只更新文档，未修改权限。

### 5. scripting 理由

用于扩展安装或更新后，在已经打开的普通 HTTP/HTTPS 网页中加载扩展包内的 content-widget.js；也用于用户点击工具栏图标时，恢复尚未加载页面脚本的当前网页。新加载网页由清单声明的内容脚本自动初始化。注入的代码全部随扩展包提供，仅实现悬浮球、输入框连接与提示词复用，不下载或执行远程脚本。

### 6. sidePanel 理由

用于显示 Microsoft Edge 原生侧边栏，承载提示词读取、保存、搜索、复制、插入以及管理页入口。用户点击网页悬浮球打开侧边栏，点击最小化关闭侧边栏并恢复悬浮球。侧边栏与网页输入框交互，方便用户在浏览网页时复用本地提示词。

### 7. 主机权限理由

http://*/* 和 https://*/* 用于在用户允许的网站上自动显示悬浮球，并在刷新、跳转和切换普通网页后继续提供提示词入口。扩展面向不同网站的通用文本输入框，不能限定在单个域名。页面脚本在本地内存中跟踪最近使用的符合条件的输入框，供侧边栏读取和插入；只有用户点击保存后才将提示词及来源站点、路径和页面标题写入本地库，来源地址去除查询参数和片段。扩展不抓取整站内容，不上传网页数据；浏览器受保护页面不支持注入。

### 9. 数据使用量：哪些用户数据？

不能将“数据不上传”直接等同于“没有访问或处理数据”。按截图字段涵盖的实际本地处理行为，建议勾选以下三项，并在隐私政策中说明范围：

| 选项 | 建议 | 当前版本依据 |
| --- | --- | --- |
| 个人身份信息 | 不勾选 | 不专门要求或提取姓名、邮箱、年龄等身份字段；用户自行写入提示词的内容按网站内容处理。 |
| 健康信息 | 不勾选 | 不提供健康数据采集功能。 |
| 财务和付款信息 | 不勾选 | 不提供交易或付款数据采集功能，并尝试排除可识别的敏感输入框。 |
| 身份验证信息 | 不勾选 | 不读取浏览器凭据、Cookie 或令牌库，并尝试排除密码和验证码等输入框。 |
| 个人通信 | 不勾选 | 不遍历或收集邮件、短信、聊天记录；用户选择的编辑区文本仅用于提示词功能。 |
| 位置 | 不勾选 | 不请求定位，也不采集 IP 地址或 GPS 信息。悬浮球屏幕坐标不是地理位置。 |
| Web 历史记录 | **勾选** | 保存提示词时记录来源站点、路径和页面标题；不获取完整浏览历史。 |
| 用户活动 | **勾选** | 为读取和插入而监听符合条件输入框的焦点、输入与选区变化，并本地记录提示词使用次数、最近使用时间和悬浮球位置；不做广告跟踪或远程行为分析。 |
| 网站内容 | **勾选** | 读取用户使用的输入框文本，主动保存提示词及历史版本，并按用户操作插入或复制。 |

以上“不勾选”指没有针对这些类别的专门采集功能，不保证自由文本永远不含个人或敏感信息。若今后增加邮件读取、个人资料提取、云同步等功能，需要重新评估披露，不能沿用此表。
