一个本地优先的 Chrome / Edge 浏览器插件，用于保存、搜索、插入提示词，并保留每次编辑的历史版本。

本版基于 0.6.0，沿用本地提示词库与正文变更时新增版本的规则。原始 0.6.0 保存在 `versions/0.6.0`。

开发者模式使用当前项目根目录；已加载此目录的用户直接重新加载扩展即可。

## 安装

1. 打开 Chrome 的 `chrome://extensions`，或 Edge 的 `edge://extensions`。
2. 开启“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择本项目文件夹。

如果已经加载过旧版本，请在扩展管理页点击一次“重新加载”。允许在所有网站上运行后，普通网页会自动显示悬浮球，无需逐页点击插件。

插件面向 Microsoft Edge / Chrome（Chromium 142 或更高版本、Manifest V3），使用原生侧边栏打开、关闭事件。升级后请在扩展管理页重新加载一次。

## 使用

- 普通 HTTP/HTTPS 网页自动显示紫色 `P` 小球，刷新、跳转和切换标签页后仍可使用；浏览器网站访问设置需允许所有网站。
- 小球可以拖动到合适位置，并会记住位置；点击小球打开原生侧边栏，并隐藏该窗口各网页的小球；点击 `—` 关闭侧边栏并恢复小球；点击 `×` 关闭侧边栏和当前页小球。再次点击工具栏插件图标可重新显示。
- 小球在窗口四边保留 8px 安全距离；旧版本保存的位置会自动迁移到新的坐标格式。
- 侧边栏只保留读取、重新读取、保存、搜索、插入、复制和管理入口。
- 侧边栏中的每条提示词都可直接复制或删除；删除前会再次确认。
- 在网页输入框中输入内容后点击小球，面板会自动读取，点击“保存”即可入库。
- 点击“保存”后可选填提示词标题；也可以点击“先不填写”，由插件根据正文自动生成标题。
- 对已保存的相同正文再次填写标题并保存，会更新原提示词标题而不会创建重复记录。
- 插件不会在后台自动保存网页输入。点击小球会读取最近使用的非敏感输入框；只有点击“保存”后才会写入提示词库。
- 完全相同的内容不会重复保存；需要生成新版本时，请在管理页中编辑并保存。
- 历史版本、恢复和备份统一放在管理标签页中；先打开悬浮助手，再点击“管理”，将在新的浏览器标签页打开原管理页面。
- 侧边栏与管理页共用同一个本地提示词库；任一入口保存、删除或更新数据，另一个入口会实时同步。
- 先选中网页输入框，再从面板点击提示词，可直接在光标位置插入。
- 保存网页内容：先点击网页输入框，再打开插件并点击“保存”。
- 插入提示词：先点击目标输入框，打开插件后点击提示词条目。
- 如果网页不支持直接插入，插件会自动复制到剪贴板。
- 每次修改提示词正文并保存，都会产生一个新版本；恢复旧版本也不会删除后续记录。
- 数据只保存在当前浏览器，可在“数据管理”中导入或导出 JSON 备份。
- 来源只保存网页站点、路径和标题，不保存查询参数或网址片段中的令牌信息。

## 当前范围

- 支持常规 `input`、`textarea` 和 `contenteditable` 输入区域。
- 支持开放式 Shadow DOM 中的常规输入框；出于权限和界面一致性考虑，暂不读取 iframe 内的输入框。
- 复杂画布编辑器及自行接管输入事件的编辑器可能只能使用复制功能。
- 浏览器内部页面、扩展商店等受保护页面无法读取或写入。
- 常驻小球只运行在普通 HTTP/HTTPS 网页，浏览器设置页和新标签页不会显示。
- 暂不包含账号、云同步、标签、文件夹、模板变量和 AI 分类。

## 隐私与权限

- HTTP/HTTPS 网站权限与自动页面脚本：在普通网页显示悬浮球并连接输入框。
- `activeTab` 与 `scripting`：恢复当前页悬浮球及初始化已打开网页。
- `sidePanel`：显示和收起浏览器原生侧边栏。
- `storage`：在当前 Edge 配置中保存提示词、历史版本和悬浮球位置。
- `downloads`：将用户主动导出的 JSON 备份保存到本地。
- 插件不包含网络请求、远程脚本、账号系统、分析统计或云端同步。
- 详细说明见 `PRIVACY.md`。
